# Developer Portfolio

## Author

Oskari Antintupa

## Project Description

This project is a responsive developer portfolio website created as part of the Software Development Skills Front-End course. The project is based on the SaaS Landing Page tutorial and was modified into a personal portfolio website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Font Awesome

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively:

1. Open the project in Visual Studio Code.
2. Open `index.html` using Live Server.
